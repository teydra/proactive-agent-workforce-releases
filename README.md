# Autark has moved to OpenAutark

Autark's downloads, updates and release notes now live in **[teydra/OpenAutark](https://github.com/teydra/OpenAutark)**.

- Windows: [autark-windows-x64.exe](https://github.com/teydra/OpenAutark/releases/latest/download/autark-windows-x64.exe)
- Mac: [autark-mac-universal.dmg](https://github.com/teydra/OpenAutark/releases/latest/download/autark-mac-universal.dmg)
- Linux: [autark-linux-x64.AppImage](https://github.com/teydra/OpenAutark/releases/latest/download/autark-linux-x64.AppImage)
- Android: [autark-android.apk](https://github.com/teydra/OpenAutark/releases/latest/download/autark-android.apk)
- [Checksums](https://github.com/teydra/OpenAutark/releases/latest/download/SHA256SUMS.txt)

This repository keeps the releases up to 0.3.3. Release 0.3.3 here is the same as in OpenAutark: an Autark up to 0.3.2
updates from here to 0.3.3 and from then on reads OpenAutark. If your Autark says "Could not check for updates", download
the current version from OpenAutark once; your data stays where it is.
